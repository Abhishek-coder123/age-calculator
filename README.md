# 🧮 Age Calculator

A simple and responsive **Age Calculator** built using **HTML, CSS, and JavaScript**.

Enter your date of birth to calculate your exact age in **years, months, and days**.

## 🚀 Live Demo

[View Live Demo](https://abhishek-coder123.github.io/age-calculator/)

## ✨ Features

- 📅 Enter your date of birth
- 🎯 Calculates age in years, months, and days
- ⚡ Instant results
- 📱 Responsive design
- 🎨 Simple and clean user interface
- ❌ Handles invalid date inputs

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
